# Питание и рацион

## О проекте

Финальный проект спринта, закрепляющий все навыки, полученные за предыдущие дни: работу с данными (Pandas, SQL), визуализацию, машинное обучение и организацию кода по принципам ООП.

Цель проекта — создать **приложение-нутрициолог**, которое по списку ингредиентов:

- предсказывает рейтинг потенциального блюда (`bad`, `so-so`, `great`);
- находит и возвращает все нутриенты (белки, жиры, натрий и т. п.) в ингредиентах, а также их суточные нормы в %;
- находит 3 наиболее похожих рецепта с рейтингами и URL-адресами.

В предисловии подчёркивается идея сбалансированного питания (Парацельс: «Всё — яд, и всё — лекарство; то и другое определяет доза») и три ключевые проблемы современного человека: скудный рацион, любовь к вредной еде и незнание хороших рецептов. Проект призван решить их с помощью данных и ML.

Работа состоит из трёх этапов: **исследование** (Jupyter Notebook), **разработка** (Python-модуль с классами) и **основная программа** (Python-скрипт).

## Что было сделано

### Исследование (recipes.ipynb)

#### Прогноз

**Подготовка данных**
- Использован датасет **Epicurious dataset** (собран HugoDarwood).
- Отфильтрованы «не-ингредиентные» столбцы: предсказание рейтинга выполняется **только по ингредиентам**, без дополнительных признаков.

**Регрессия**
- Попробованы разные алгоритмы и их гиперпараметры для предсказания рейтинга.
- Лучшая модель выбрана по кросс-валидации, метрика **RMSE** посчитана на тестовой подвыборке.
- Попробованы ансамбли и их гиперпараметры; лучший выбран по кросс-валидации и оценён на тесте.
- Посчитан RMSE **наивного регрессора**, предсказывающего средний рейтинг, — для сравнения.

**Классификация**
- Целевой столбец бинаризован округлением рейтингов до ближайшего целого.
- Попробованы разные алгоритмы и гиперпараметры; лучший выбран по кросс-валидации, метрика **accuracy** — на тесте.
- Сравнены метрики, посчитана accuracy **наивного классификатора** (всегда предсказывает самый частый класс).
- Целевой столбец преобразован в три класса: `bad` (0, 1), `so-so` (2, 3), `great` (4, 5).
- Снова подобраны алгоритмы и гиперпараметры, выбрана лучшая модель, посчитана accuracy на тесте.
- Проанализирован вопрос о типах ошибок: что хуже — предсказать «плохой» рейтинг, когда он хороший, или наоборот? Accuracy заменена на более подходящую метрику.
- С новой метрикой снова подобраны алгоритмы и гиперпараметры, выбрана лучшая модель.
- Попробованы ансамбли, выбрана лучшая модель, посчитана метрика на тесте.

**Решение**
- Определено, что лучше использовать в программе: регрессию или классификацию.
- Сохранена лучшая модель — она используется в основном скрипте.

#### Пищевая ценность (Nutrition Facts)
- Собраны в один DataFrame все пищевые значения по ингредиентам из подготовленного и отфильтрованного датасета (только столбцы-ингредиенты) с использованием [API USDA](https://fdc.nal.usda.gov/api-guide.html).
- Все значения преобразованы в **% от суточной нормы (Daily Value)**.
- Оставлены только те нутриенты, которые есть в предоставленных таблицах.
- Преобразованный DataFrame сохранён в **CSV-файл** для использования в основной программе.

#### Похожие рецепты (Similar Recipes)
- Для каждого рецепта из датасета собран URL на epicurious.com с подробностями (рецепты без URL пропущены).
- Новый DataFrame сохранён в **CSV-файл** для использования в основной программе.

### Разработка (recipes.py)
- Создан Python-модуль с **классами и методами**, которые используются в основном скрипте.
- Код организован по принципам **ООП**: вся логика инкапсулирована в классы, глобальная область программы не используется.

### Основная программа (nutritionist.py)
- Python-скрипт, принимающий список ингредиентов.
- **Прогноз**: предсказывает и возвращает класс рейтинга блюда (`bad`, `so-so`, `great`).
- **Пищевая ценность**: находит и возвращает все нутриенты (белки, жиры, натрий и т. п.) в ингредиентах, а также их суточные нормы в %.
- **Похожие рецепты**: находит 3 наиболее похожих рецепта с рейтингами и URL-адресами с полными подробностями.


### Бонусная часть
- В классы добавлены новые методы, позволяющие скрипту генерировать **меню на день**.
- Дневное меню случайным образом подбирает три рецепта, которые:
  - покрывают основную часть суточной потребности в нутриентах (в % от дневной нормы), не превышая её;
  - имеют наибольшую суммарную оценку.
- Предлагаются только рецепты, подходящие для **завтрака, обеда и ужина** соответственно.
