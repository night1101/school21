# SQL и Pandas

## О проекте

Проект посвящён освоению **SQL** и его интеграции с **Pandas**. В ходе работы были изучены основные приёмы работы с реляционными базами данных: выборка данных, подзапросы, соединения (JOIN), агрегации и проведение упрощённого A/B-тестирования.

Работа велась с реальным набором данных образовательной компании, которая добавила на свою платформу страницу «Лента новостей» (Newsfeed) с целью создать эффект социального давления (peer pressure) и побудить студентов раньше начинать работу над лабораторными. В серии упражнений проверялась гипотеза о том, повлияла ли эта страница на поведение студентов.

Все задания выполнены в Jupyter Notebook. Соединение с базой данных SQLite осуществлялось через библиотеку `sqlite3`, а извлечение данных — через `pd.io.sql.read_sql()`.

## Что было сделано

### ex00 — Выборка (SELECT)
- Файл базы данных SQLite размещён в подпапке `data`.
- Установлено соединение с базой через `sqlite3`.
- Получена схема таблицы `pageviews` с помощью запроса `PRAGMA table_info(pageviews);`.
- Выведены первые 10 строк таблицы `pageviews` для ознакомления со структурой.
- Одним SQL-запросом получена подтаблица:
  - только столбцы `uid` и `datetime`;
  - только пользовательские данные (`user_*`), администраторы исключены;
  - сортировка по `uid` по возрастанию;
  - столбец `datetime` использован как индекс и преобразован в `DatetimeIndex`.
- Результат сохранён в DataFrame `pageviews`, соединение закрыто.

### ex01 — Подзапрос (SUBQUERY)
- Установлено соединение с базой через `sqlite3`.
- Получена схема таблицы `checker` и её первые 10 строк.
- Одним запросом (с подзапросами) подсчитано количество строк из `pageviews`, соответствующих записям из `checker` со следующими условиями:
  - `status = 'ready'`;
  - `numTrials = 1` (только первые коммиты);
  - `labname` входит в список активных лабораторных: `laba04`, `laba04s`, `laba05`, `laba06`, `laba06s`, `project1`.
- Результат сохранён в DataFrame с колонкой `cnt`, соединение закрыто.

### ex02 — Соединение (JOIN)
- Установлено соединение с базой через `sqlite3`.
- Одним запросом создана витрина данных `datamart`, объединяющая таблицы `pageviews` и `checker` со столбцами:
  - `uid`, `labname`, `first_commit_ts`, `first_view_ts`.
- Применены фильтры: `status = 'ready'`, `numTrials = 1`, список активных лабораторных, только пользователи (`user_*`).
- Столбцы `first_commit_ts` и `first_view_ts` приведены к типу `datetime64[ns]`.
- С помощью Pandas созданы два DataFrame:
  - `test` — пользователи с заполненными `first_view_ts`;
  - `control` — пользователи с пропущенными `first_view_ts`; пропуски заменены средним значением `first_view_ts` из группы `test`.
- Обе таблицы сохранены в базе для дальнейшего использования, соединение закрыто.

### ex03 — Агрегации
- Установлено соединение с базой через `sqlite3`.
- Получены схема и первые 10 строк таблицы `test`.
- Одним запросом найдена **минимальная** дельта между первым коммитом и дедлайном лабораторной (в часах), с объединением с таблицей `deadlines`; `project1` исключён. Результат — `df_min` с соответствующим `uid`.
- Аналогично найдена **максимальная** дельта (`df_max`).
- Аналогично найдена **средняя** дельта (без колонки `uid`) — `df_avg`.
- Для проверки гипотезы о влиянии числа посещений ленты на дельту:
  - одним запросом создана таблица с колонками `uid`, `avg_diff`, `pageviews`;
  - `avg_diff` — средняя дельта по пользователю, `pageviews` — число посещений ленты;
  - `project1` исключён;
  - результат сохранён в `views_diff`;
  - через метод `corr()` вычислен коэффициент корреляции между числом просмотров и дельтой.
- Соединение закрыто.

### ex04 — A/B-тестирование
- Установлено соединение с базой через `sqlite3`.
- Одним запросом на группу созданы два DataFrame: `test_results` и `control_results` с колонками `time` и `avg_diff` и ровно двумя строками:
  - `time` принимает значения `after` и `before`;
  - `avg_diff` — средняя дельта для пользователей за периоды до и после первого визита на страницу;
  - учитывались только пользователи с наблюдениями и «до», и «после».
- Лабораторная `project1` исключена.
- Соединение закрыто.
- Сделан вывод о подтверждении гипотезы: сравнивалось поведение групп `test` и `control` до и после первого визита на «Ленту».
