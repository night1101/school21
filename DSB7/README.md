# Pandas: работа с DataFrame

## О проекте

Проект посвящён освоению библиотеки **Pandas** — одного из ключевых инструментов Data Science на Python. В ходе работы были изучены и применены на практике основные приёмы работы с табличными данными: загрузка и сохранение, предобработка, выборки, агрегации, обогащение и оптимизация производительности.

Все задания выполнены в Jupyter Notebook с использованием только разрешённых импортов (`pandas`, `numpy`, `requests`, `gc`).

## Что было сделано

### ex00 — Загрузка и сохранение
- Загружен лог-файл посещений страницы в DataFrame через `read_csv`.
- Отфильтрованы фейковые строки с помощью аргументов `skiprows` и `skipfooter`.
- Заданы имена столбцов `datetime` и `user`, столбец `datetime` сделан индексом.
- Индекс переименован в `date_time`.
- Данные сохранены в файл `feed-views-semicolon.log` с разделителем `';'` через `to_csv`.

### ex01 — Базовые операции
- Создан DataFrame `views` из лог-файла, столбец `datetime` приведён к типу `datetime64[ns]`.
- Из даты извлечены год, месяц, день, час, минута и секунда в отдельные столбцы.
- Создан столбец `daytime` с категориями времени суток (night, early morning, morning, afternoon, early evening, evening) с помощью метода `cut`.
- Столбец `user` назначен индексом.
- Подсчитано общее количество записей (`count()`) и распределение по категориям `daytime` (`value_counts()`).
- Выполнена сортировка по часам, минутам и секундам одновременно.
- Найдены минимумы, максимумы и моды для часов и категорий `daytime`, а также примеры пользователей для конкретных часов.
- Получены три самых ранних и три самых поздних часа с именами пользователей (`nsmallest()` / `nlargest()`).
- Через `describe()` вычислена базовая статистика, из которой извлечён интерквартильный размах (IQR) для часа.

### ex02 — Предобработка данных
- Прочитан CSV-файл с `ID` в качестве индексного столбца.
- Удалены дубликаты по столбцам `CarNumber`, `Make_n_Model`, `Fines` с сохранением последнего наблюдения.
- Проанализированы пропущенные значения: удалены столбцы с более чем 500 пропусками (`thresh`).
- Пропуски в `Refund` заполнены предыдущим значением (`method`), в `Fines` — средним значением.
- Столбец `Make_n_Model` разбит на `Make` и `Model` через `apply`, исходный столбец удалён.
- Результат сохранён в `auto.json`.

### ex03 — Выборки и агрегации
- Загружен JSON-файл из ex02, индекс — `CarNumber`.
- Выполнены выборки по условиям: штрафы > 2100, штрафы > 2100 и refund = 2, модель из списка, номер из списка.
- Проведены агрегации по `Make` и `Model`: медиана, количество, минимум/максимум и стандартное отклонение штрафов.
- Выполнены агрегации по номерам автомобилей: топ по количеству штрафов и топ по сумме штрафов с детализацией строк.
- Построена таблица, показывающая, привязаны ли номера автомобилей к разным моделям.

### ex04 — Обогащение и преобразования
- Прочитан JSON из ex02, настроен формат отображения float-чисел (`float_format`).
- Создан сэмпл из 200 наблюдений (`random_state = 21`) без новых комбинаций car number / make / model, объединён с исходным DataFrame в `concat_rows`.
- Добавлен столбец `Year` со случайными целыми числами от 1980 до 2019 (`np.random.seed(21)`), получен DataFrame `fines`.
- Создан DataFrame `owners` с владельцами автомобилей на основе популярных американских фамилий.
- Выполнены добавление и удаление наблюдений, а затем различные виды соединений (`merge`): inner, outer, left, right.
- Построена сводная таблица (pivot table) с суммами штрафов по годам.
- DataFrames `fines` и `owners` сохранены в CSV без индекса.

### ex05 — Оптимизации Pandas
- Прочитан `fines.csv`, для каждой строки вычислено `fines / refund * year` и добавлено в новый столбец.
- Сравнена производительность (`%%timeit`) разных способов итерации:
  - цикл `for` с `iloc` и `append()`;
  - `iterrows()`;
  - `apply()` с лямбда-функцией;
  - объекты `Series`;
  - `.values`.
- Сравнена скорость индексации до и после установки `CarNumber` в качестве индекса.
- Выполнен downcasting типов: `float64 → float32`, `int64 → минимально возможный int`.
- Столбцы типа `object` преобразованы в `category`, что позволило значительно сократить потребление памяти.
- Исходный DataFrame удалён из памяти с помощью `gc` и `%reset_selective`.
