# Pandas, SQL и визуализация данных

## О проекте

Проект посвящён освоению **визуализации данных** в Python с использованием трёх ключевых библиотек: **Matplotlib**, **Seaborn** и **Plotly**. Работа велась с реальными данными образовательной платформы, с которыми уже приходилось работать в предыдущих проектах (SQL и Pandas). Основная задача — научиться не только считать метрики, но и наглядно их представлять, а также глубже понимать данные через графики.

В предисловии проекта приводится классический пример **квартета Энскомба**: четыре набора данных с одинаковыми числовыми характеристиками, которые при визуализации оказываются совершенно разными. Это подчёркивает главную идею: за цифрами важно видеть суть, и визуализация — ключевой инструмент для этого.

Все задания выполнены в Jupyter Notebook с использованием только разрешённых импортов.

## Что было сделано

### ex00 — Линейный график
- Установлено соединение с базой данных SQLite через `sqlite3`.
- Из таблицы `pageviews` получены данные о визитах только для пользователей (`user_*`), без администраторов.
- С помощью Pandas создан DataFrame с числом визитов, сгруппированных по дате.
- Построен линейный график методом `.plot()`:
  - размер шрифта — 8;
  - размер фигуры — (15, 8);
  - заголовок — "Views per day";
  - настроен поворот меток по оси X.
- Соединение с базой закрыто.

### ex01 — Линейный график со стилями
- Проанализированы только пользователи (без администраторов).
- Учтены только те даты, по которым есть и просмотры, и коммиты из таблицы `checker`.
- Построен сдвоенный график по двум метрикам, воссоздающий пример:
  - размер шрифта — 8;
  - размер фигуры — (15, 8).
- В конце блокнота добавлена markdown-ячейка с вопросом: «Сколько раз число просмотров превышало 150?» и ответом.

### ex02 — Столбчатая диаграмма
- Проанализированы коммиты пользователей (без администраторов).
- Данные разбиты на интервалы времени суток:
  - night — 0:00–3:59:59;
  - morning — 4:00–9:59:59;
  - afternoon — 10:00–16:59:59;
  - evening — 17:00–23:59:59.
- Построена столбчатая диаграмма распределения коммитов по времени суток с сохранением размеров шрифта и фигуры.
- В markdown-ячейке даны ответы:
  - две самые частые категории времени суток;
  - день с максимальным числом коммитов, где вечером коммитов больше, чем днём.

### ex03 — Столбчатые диаграммы
- Проанализированы коммиты пользователей (без администраторов).
- Для каждого часа посчитано среднее число коммитов отдельно для рабочих дней и выходных.
- Построен сдвоенный столбчатый график для будней и выходных.
- В markdown-ячейке указан час с наибольшим числом коммитов в будни и аналогичный топовый час в выходные.

### ex04 — Гистограмма
- Проанализированы коммиты пользователей (без администраторов).
- Подготовлены два списка значений: отдельно для рабочих дней и для выходных.
- Построена гистограмма с прозрачностью переднего слоя `alpha = 0.7`.
- В markdown-ячейке приведены топ-4 часа, когда общее число коммитов было выше в выходные, чем в рабочие дни.

### ex05 — Диаграмма размаха (boxplot)
- Загружен файл с данными о поведении экспериментальной и контрольной групп.
- Построен boxplot для сравнения распределений:
  - палитра — как в примере;
  - размер шрифта заголовка — 15;
  - толщина линий «ящиков» — 3, толщина линий медианы — 2.
- В markdown-ячейке указан приблизительный IQR контрольной группы до появления ленты новостей (округлён до ближайшего десятка).

### ex06 — Матрица диаграмм рассеяния (scatter matrix)
- Построен DataFrame, где для каждого пользователя из группы `test` собраны:
  - средняя дельта между первым коммитом и дедлайном;
  - число визитов в «Ленту»;
  - число коммитов.
- `project1` исключён при расчётах средней дельты и числа коммитов.
- Построена матрица диаграмм рассеяния:
  - размер точек — 200;
  - толщина линий KDE на диагонали — 3.
- В markdown-ячейке даны ответы «да/нет» на четыре вопроса о связях между просмотрами, коммитами и дельтой.

### ex07 — Тепловая карта (heatmap) — бонус
- Проанализированы коммиты пользователей (без администраторов) с использованием таблицы `checker`.
- Использованы абсолютные числа коммитов.
- DataFrame отсортирован по общему числу коммитов пользователя.
- Построены две тепловые карты (по дням недели и по часам) с использованием `make_axes_locatable`.
- В markdown-ячейке даны ответы:
  - пользователь с наибольшим числом коммитов во вторник;
  - пользователь с наибольшим числом коммитов в четверг;
  - день недели с наименьшим числом коммитов;
  - пользователь и час с наибольшим числом коммитов.

### ex08 — Seaborn
- Проанализированы коммиты пользователей (без администраторов) по логам `checker` со статусом `ready`.
- Построен линейный график динамики коммитов по пользователям в `project1`:
  - `linewidth = 3`;
  - серый фон;
  - высота — 10, ширина — в 1.5 раза больше;
  - размер шрифта заголовка — 30, подписей осей — 15.
- В markdown-ячейке определены:
  - пользователь, почти всё время лидировавший по числу коммитов;
  - пользователь, лидировавший лишь недолгое время.

### ex09 — Plotly
- Построен интерактивный анимированный линейный график (line race), аналогичный графику из ex08, но средствами Plotly.
- Использованы `plotly.graph_objects` и `numpy`.
- При реализации опирался на пример из официального репозитория (lineRace.py).
