# Введение в машинное обучение

## О проекте

Проект посвящён освоению базовых задач **машинного обучения** на Python с использованием библиотеки **scikit-learn**. Работа велась с реальными данными образовательной платформы, с которыми уже приходилось работать в предыдущих проектах (SQL, Pandas, визуализация). Основная цель — познакомиться с двумя ключевыми типами задач (обучение с учителем и без учителя), научиться обучать модели, оценивать их качество и избегать типичных ошибок.

В предисловии проекта разъясняется иерархия понятий: **искусственный интеллект** ⊃ **машинное обучение** ⊃ **нейронные сети** ⊃ **глубокое обучение**. Отдельно подчёркивается, что любой алгоритм машинного обучения требует качественных данных: «если данные — мусор, то и знания на выходе будут мусором».

Все задания выполнены в Jupyter Notebook с использованием только разрешённых импортов.

## Что было сделано

### ex00 — Бинарный классификатор
- Изучены базовые понятия: обучение с учителем vs без учителя, классификация vs регрессия, конструирование признаков.
- Построен бинарный классификатор на логистической регрессии, предсказывающий, был ли коммит сделан в **рабочий день** или в **выходной**.
- В качестве признаков сконструированы:
  - число коммитов до полудня;
  - число коммитов после полудня.
- Единица наблюдения — **день**.
- Модель обучена, проверено её качество на исходных данных.

### ex01 — Границы решений
- Изучено, как работает логистическая регрессия «под капотом».
- Обучены и сравнены три алгоритма классификации:
  - логистическая регрессия;
  - SVM (метод опорных векторов);
  - дерево решений.
- Результаты визуализированы для сравнения границ решений.
- Предприняты шаги по повышению качества моделей.

### ex02 — Мультикласс
- Освоена задача **мультиклассовой** классификации (в отличие от multilabel).
- Выполнено кодирование категориальных признаков методом **one-hot**.
- Обучена мультиклассовая модель, предсказывающая **день недели** коммита по признакам:
  - кто сделал коммит;
  - во сколько;
  - по какой лабораторной;
  - сколько попыток уже было.
- Проанализирована важность признаков для разных алгоритмов.
- Дополнительно опробован алгоритм **Random Forest** (метод случайного леса).

### ex03 — Переобучение
- Разобрано понятие **переобучения**: модель может «запомнить» обучающие данные и показывать нереалистично высокую точность на них.
- Освоены способы борьбы с переобучением:
  - **train/test split** — разбиение на обучающую и тестовую выборки;
  - **кросс-валидация** — проверка качества на нескольких разбиениях.
- Проведено сравнение оценки качества модели при разных подходах.

### ex04 — Регрессия
- Освоена задача **регрессии** — предсказание непрерывной целевой переменной.
- Построена модель, предсказывающая **среднюю дельту** между дедлайнами и первым коммитом для каждого пользователя.
- Использованы признаки:
  - данные о просмотрах «Ленты новостей»;
  - количество сделанных коммитов за время прохождения программы.
- Оценено качество регрессионной модели.

### ex05 — Кластеризация
- Освоено **обучение без учителя** на примере алгоритмов кластеризации.
- Выполнено разбиение пользователей на однородные группы.
- Проанализированы полученные кластеры для потенциальной разработки:
  - дополнительных триггеров;
  - механик вовлечения, отличающихся в зависимости от поведения пользователей.

- Различение задач классификации и регрессии.
- Конструирование признаков (feature engineering) из временных меток.
- Обучение и сравнение алгоритмов: логистическая регрессия, SVM, дерево решений, Random Forest.
- One-hot кодирование категориальных признаков.
- Мультиклассовая классификация и оценка важности признаков.
- Борьба с переобучением: train/test split и кросс-валидация.
- Построение регрессионных моделей.
- Кластеризация и интерпретация групп пользователей.
- Оценка качества моделей машинного обучения.
