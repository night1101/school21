# Анализ MovieLens

## О проекте

Проект посвящён подготовке **аналитического отчёта** по данным MovieLens и закреплению всех навыков, полученных за предыдущие дни. Основная задача — применить силу сторителлинга в Data Science: не просто посчитать метрики, а рассказать увлекательную историю о данных, используя собственный модуль с классами и методами.

В предисловии подчёркивается идея, что в основе кинематографа лежит древний механизм — **искусство рассказывания историй**. Хорошие аналитические отчёты также содержат элементы сторителлинга, и этот проект предлагает освоить этот навык на практике.

Работа состоит из двух частей: **модуль** (`movielens_analysis.py`) с классами, методами и тестами, и **отчёт** (`movielens_report.ipynb`), построенный исключительно на этом модуле.


---

## Что было сделано

### Модуль (movielens_analysis.py)

- Использован **уменьшенный набор данных MovieLens**: скачан и взяты первые **1000 записей**.
- Внимательно изучен файл `README.txt`, разобраны структуры всех файлов данных.
- Создан модуль с **четырьмя классами**, соответствующими четырём файлам данных:
  - **Ratings** — работа с файлом рейтингов;
  - **Tags** — работа с файлом тегов;
  - **Movies** — работа с файлом фильмов;
  - **Links** — работа с файлом ссылок.
- Дополнительно создан **класс Tests** для тестирования.
- Реализованы все обязательные методы для каждого класса (см. примеры кода в задании).
- Добавлены вспомогательные методы, где это было полезно для повышения удобства и читаемости.
- Код организован по принципам **ООП**: без кода в глобальной области видимости, вся логика инкапсулирована в классах и функциях.
- Любые необработанные исключения отсутствуют — все потенциальные ошибки обработаны.

### Тесты (PyTest)

- Созданы тесты с помощью **PyTest** для каждого метода классов `Ratings`, `Tags`, `Movies`, `Links`.
- Тесты проверяют:
  - что методы возвращают данные **корректных типов**;
  - что элементы списков имеют **корректные типы**;
  - что возвращаемые данные **отсортированы корректно**.
- Все тесты успешно запущены перед переходом к этапу отчёта.
- В бонусной части тесты улучшены: добавлены проверки корректности вычислений (ручной пересчёт некоторых результатов и метрик на конкретных входных данных).

### Отчёт (movielens_report.ipynb)

- Отчёт подготовлен в **Jupyter Notebook** с использованием **только** классов и методов из `movielens_analysis.py`.
- Соблюдены все ограничения:
  - использованы **все методы** из `movielens_analysis.py` (кроме класса Tests);
  - каждая ячейка содержит магическую команду **`%timeit`**;
  - все прочие импорты и встроенные функции вынесены в модуль — в блокноте они запрещены.
- Отчёт рассказывает **интересную историю** о наборе данных MovieLens: подобрана логика и последовательность изложения, объединяющая результаты разных методов в связное повествование.
- В бонусной части отчёт развит в интерактивный формат **«вопрос–ответ»**: сделан увлекательным, эмоциональным, интересным и лёгким для чтения.
- Добавлены дополнительные полезные методы в классы (с тестами) для обогащения отчёта.

## Ключевые навыки

- Организация кода по принципам **ООП**: классы, методы, инкапсуляция.
- Работа с реальным набором данных MovieLens и разбор его структуры.
- Написание **модульных тестов** с помощью PyTest.
- Проверка корректности типов, сортировки и вычислений.
- Построение **аналитического отчёта** на основе собственного модуля.
- Использование магической команды `%timeit` для оценки производительности.
- Применение **сторителлинга** в Data Science: превращение сухих цифр в увлекательную историю.
- Создание интерактивного отчёта в формате «вопрос–ответ».
- Строгое соблюдение ограничений (запрет на импорты и встроенные функции в отчёте).
- Обработка исключений и отсутствие необработанных ошибок.
- Презентация, объяснение и обоснование принятых решений на peer-review.
