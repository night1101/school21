# Машинное обучение: продвинутый уровень

## О проекте

Проект посвящён освоению **продвинутых техник машинного обучения** на Python с использованием библиотеки **scikit-learn**. Работа продолжает серию проектов по Data Science и ведётся с реальными данными образовательной платформы (логи коммитов студентов), с которыми уже приходилось работать ранее.

Основная цель — перейти от базовых моделей к более сложным инструментам: регуляризации, автоматическому подбору гиперпараметров, правильному выбору метрик, ансамблевым методам и организации кода в виде конвейеров (pipelines) с применением принципов ООП.

В предисловии подчёркивается важное различие между **прикладным** и **соревновательным** Data Science: в бизнесе, помимо качества модели, важны интерпретируемость, скорость работы, ресурсоёмкость и бизнес-контекст; на соревновательных платформах вроде Kaggle — только целевая метрика. Проект показывает обе стороны этой сферы.

Все задания выполнены в Jupyter Notebook с использованием только разрешённых импортов.

## Что было сделано

### ex00 — Регуляризация
- Освоено понятие **регуляризации** как способа борьбы с переобучением.
- Изучены виды регуляризации логистической регрессии:
  - **L1** — обнуляет часть коэффициентов, помогает отбирать признаки;
  - **L2** — уменьшает веса, не обнуляя их.
- Изучены параметры регуляризации для деревьев и лесов: `max_depth`, `min_samples_split`, `min_samples_leaf`, `max_leaf_nodes`.
- На том же датасете (предсказание дня недели коммита по `uid`, `labname`, `numTrials` и часу коммита) проведены эксперименты с разными параметрами регуляризации.
- Сравнено влияние параметров на качество модели.

### ex01 — Поиск по сетке (GridSearch)
- Освоена автоматизация подбора гиперпараметров с помощью **GridSearchCV**.
- Заданы диапазоны значений гиперпараметров для разных моделей.
- Выполнен полный перебор комбинаций с оценкой метрик на кросс-валидации.
- Получены лучшие наборы гиперпараметров и сводки результатов мини-исследования.

### ex02 — Метрики
- Разобрана проблема **несбалансированных классов** и ограниченность метрики accuracy (на примере антифрода, где мошеннических транзакций мало).
- Изучены метрики, основанные на **матрице ошибок (confusion matrix)**:
  - **precision** — доля правильных предсказаний среди всех предсказаний класса;
  - **recall** — доля правильных предсказаний среди всех объектов класса;
  - **F1-мера** — гармоническое среднее precision и recall.
- Изучена **ROC-кривая** и **AUC** (площадь под ROC-кривой) как способ сравнения моделей из разных задач.
- Рассмотрены практические примеры: когда важнее precision (реклама 16+), а когда recall (поиск террористов).
- Применены метрики на практике и сравнены модели.

### ex03 — Ансамбли
- Освоены ансамблевые методы, объединяющие несколько моделей:
  - **VotingClassifier** — голосование нескольких моделей;
  - **BaggingClassifier** — обучение базовых моделей на подвыборках;
  - **StackingClassifier** — объединение моделей через мета-модель.
- Проведено сравнение качества одиночных моделей и ансамблей.
- Сделаны выводы о том, какие подходы дают лучший результат на данном датасете.

### ex04 — Конвейеры (pipelines) и ООП
- Осознана проблема «хаотичного» кода, размазанного по разным блокнотам.
- Применён подход **ООП** к анализу данных:
  - первая часть блокнота содержит только импорты, классы и методы;
  - вторая часть — «основную программу».
- Пройдены все ключевые шаги пайплайна машинного обучения:
  - подготовка данных;
  - обучение разных моделей;
  - оценка метрик;
  - настройка гиперпараметров;
  - эксперименты с ансамблями.
- Код приведён к аккуратному, организованному и переиспользуемому виду — пригодному для коллег, портфолио и будущего возврата к проекту.
