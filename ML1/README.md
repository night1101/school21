# Введение в машинное обучение

## О проекте

Проект представляет собой вводный курс в **машинное обучение** и основы анализа данных на Python. В теоретической части разбираются ключевые понятия ML: этапы построения модели, типы задач (обучение с учителем и без учителя), классификация и регрессия, кластеризация, ассоциация и снижение размерности.

В практической части на реальном датасете с Kaggle (предсказание цены аренды квартиры по объявлению) отрабатываются навыки разведочного анализа данных, статистического анализа, конструирования признаков и обучения простейших моделей машинного обучения.

Все задания выполнены в Jupyter Notebook.

## Что было сделано

### 1. Introduction (Введение)
- Приведены **5 примеров применения ML** в жизни с обоснованием пользы в каждом случае.
- Задачи из таблицы и собственные примеры отнесены к соответствующим классам (supervised/unsupervised, classification/regression и т. д.).
- Разобрано различие между **multiclass** и **multilabel**.
- Проанализирован вопрос: является ли пример с ценами на жильё задачей регрессии и можно ли свести регрессию к классификации.

### 2. Introduction to Data Analysis (Введение в анализ данных)
- Импортированы библиотеки: **pandas**, **numpy**, **sklearn**, **lightgbm**, **scipy**, **statsmodels**, **matplotlib**, **seaborn**.
- Загружены данные с Kaggle (`train.json`) через Pandas.
- Определён **размер датасета** (число строк и столбцов).
- Выведен список столбцов; определён целевой столбец (`price`).
- Проведён быстрый анализ данных с помощью `info()`, `describe()`, `corr()` — объяснены результаты, проверено наличие пустых столбцов.
- Создан DataFrame только с признаками `bathrooms`, `bedrooms`, `interest_level` и целевой переменной `price`.

### 3. Statistical Data Analysis (Статистический анализ данных)
- Освежены базовые статистические понятия: среднее, медиана, мода, дисперсия, стандартное отклонение.
- Изучены распределения: дискретное равномерное, Бернулли, биномиальное, Пуассона, нормальное, экспоненциальное.
- Освоены понятия: выбросы, процентили, доверительные интервалы.
- Изучена статья о сравнении распределений: гистограммы, boxplot, KDE.
- **Анализ целевой переменной**:
  - построена гистограмма распределения `price`;
  - построен boxplot, выявлены выбросы;
  - удалены строки за пределами 1-го и 99-го процентилей;
  - построена новая гистограмма `price`, объяснён результат.
- **Анализ характеристик**:
  - определён тип столбца `interest_level`;
  - выведены значения и их количество;
  - значения закодированы (0, 1, 2);
  - построены гистограммы для `bathrooms`, `bedrooms`, выявлены выбросы.
- **Комплексный анализ**:
  - построена матрица корреляций и тепловая карта;
  - построены scatterplot'ы для визуализации связи признаков с целевой переменной.

### 4. Creating Features (Создание признаков)
- Созданы дополнительные признаки (например, квадраты существующих: `bathrooms_squared`, `bedrooms_squared`, `interest_level_squared`).
- Построена матрица корреляций с новыми признаками; проверено, коррелируют ли они с целью сильнее базовых.
- Для обучения модели использованы только признаки `bathrooms` и `bedrooms`.
- Изучена документация `PolynomialFeatures` из sklearn.
- Данные разделены на обучающую и тестовую выборки (предоставлены готовыми).
- Инициализирован `PolynomialFeatures()` со степенью 10.
- Применён `fit` и `transform` к обучающим и тестовым данным.

### 5. Обучение моделей
- Созданы две пустые таблицы результатов: `result_MAE` и `result_RMSE` с колонками `model`, `train`, `test`.
- **Линейная регрессия**:
  - инициализирована без параметров;
  - обучена, сделаны предсказания на train/test;
  - вычислены MAE и RMSE;
  - результаты внесены в таблицы под именем `linear_regression`.
- **Дерево решений**:
  - инициализировано с `random_state=21`;
  - обучено, сделаны предсказания на train/test;
  - вычислены MAE и RMSE;
  - результаты внесены под именем `decision_tree`.
- **Наивные модели**:
  - вычислены среднее и медиана `price` на train и test;
  - рассчитаны MAE и RMSE для обеих;
  - результаты внесены под именами `naive_mean` и `naive_median`.
- **Сравнение результатов**:
  - выведены итоговые таблицы `result_MAE` и `result_RMSE`;
  - определена лучшая модель.
- **Дополнительно**: проведены эксперименты со всеми признаками исходного датасета и сгенерированными признаками.
